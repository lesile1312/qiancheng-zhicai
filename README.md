# 千程智财｜青年现金流与资产决策沙盘

**在线体验：** https://lesile1312.github.io/qiancheng-zhicai/  ·  **独立仓库：** https://github.com/lesile1312/qiancheng-zhicai

## 这是一个什么产品

面向高校学生的可复现财务情景教学沙盘。用户用自然语言描述升学、就业、住房和目标支出，比较两条现金流路径，再检视安全垫与资产配置策略。页面不接入银行账户、不推荐具体金融产品，也不构成投资建议。

## 30 秒体验

1. 在「说出你的选择」中修改演示场景，或切换校园生活、城市就业、考研深造等方向。
2. 点击「生成我的现金流路径」，对比两条路线和目标前可用资金。
3. 查看 P10/P50/P90 区间、假设和安全边界，再到资产沙盘切换资金策略。
4. 导出 JSON 复现包；在相同浏览器中导入，可复核输入和结果。

## AI 与隐私

- 默认可选浏览器本机 Qwen3.5-0.8B 量化模型。首次需联网加载约 0.7 GB，并需要支持 WebGPU 的浏览器；输入留在本机。不开 AI 也能完整体验沙盘。
- 可选云端 Qwen3.8-27B（经 OpenRouter）。用户自备 API Key；服务商按账户用量计费，需先勾选授权才会发送场景文本。不要输入身份号码、账户凭据或其他敏感信息。Key 仅保存在当前页面内存，不写入仓库或 URL。
- 模型仅抽取待核对字段。确认前不应用；金额、路径与分位数由浏览器本地的确定性引擎计算。

## 如何复现

`index.html` 是完整单文件网页，无需构建步骤。部署到静态 HTTPS 主机即可访问；本机预览可在项目目录启动任意静态文件服务器后打开。相同输入、参数和固定种子会得到相同模拟结果。

页面里的收入、支出、收益率、波动率和学生案例均为演示假设，不是真实调研数据，也不代表真实市场概率。产品效果、AI 字段准确率和用户体验仍须通过实际访谈与试用验证。
