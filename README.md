# 千程智财｜青年现金流与资产决策沙盘

这是一个独立的高校经管赛道三产品仓库。它面向大学生与初入职场青年，用两条可编辑的人生路线比较现金流、阶段目标、安全垫和资产安排。金额与路径由浏览器内的确定性模拟引擎计算；AI 可从自然语言中提取待核对字段，也可根据当前情景和引擎输出实时生成短分析报告。

## 在线体验

本仓库配置了 GitHub Pages 工作流。启用 GitHub Pages 的 Actions 部署后，页面地址为：

`https://<GitHub 用户名>.github.io/<仓库名>/`

每次推送到 `main` 会自动部署。产品是纯静态网页，不需要数据库、服务器密钥或用户账号。

## 本地复现

需要 Python 3 或任意静态 HTTP 服务器。进入仓库目录运行：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。不要直接双击 `index.html`：浏览器本地模型需要 HTTPS 或 localhost 的安全上下文。

## AI 模式

### 本机免费模式：Qwen3.5-0.8B

- 使用 Transformers.js 与 ONNX 量化模型，在支持 WebGPU 的浏览器本机推理。
- 首次点击“加载模型并识别”时，从 Hugging Face 下载约 0.7 GB 模型文件；之后浏览器可复用模型缓存。
- 不需要账号或 API Key；场景文本不会发给模型服务商。模型库和权重文件仍需联网获取。
- 页面点击“生成 AI 分析报告”时，Qwen 实时生成两句定性判断；路线现金中位数、P10/P50/P90、目标达成路径占比和负现金流路径由确定性引擎计算并放在独立的报告段落。校验器会拦截模型擅自给出的数字、路线优劣结论或金融建议；报告可导出为 Markdown 文件。
- 本机模式运行在 HTTPS/localhost，模型响应由实际推理生成；若 WebGPU 不可用或加载失败，会显示失败原因，不会伪装成已生成报告。
- 设备不支持 WebGPU、浏览器内存不足或模型加载失败时，产品保留规则解析与手动输入路径。

### 云端最新模型：Qwen3.8-27B

- 通过 OpenRouter 调用 Qwen 最新开源权重 Qwen3.8-27B。
- 需要使用者自己的 OpenRouter API Key；令牌仅留在当前页面内存，不写入 `localStorage`、仓库或网址。
- 推理服务按服务商账户额度/用量计费，不能承诺永久免费。界面要求先确认数据传输；勾选后，当前场景文本和本地模拟指标会发送给 OpenRouter，用于字段提取或生成报告。不要输入姓名、账号、密码、银行卡号等敏感信息。

详细 Prompt、输入字段、报告依据和数据边界见 [`TECHNICAL-MATERIALS.md`](TECHNICAL-MATERIALS.md)。

## 数据边界与验证

- 页面中的数值是可修改的演示输入，不是银行账户数据、市场预测或调研结果。
- 现金流、目标达成率和 P10/P50/P90 输出来自本地模拟假设，不代表真实概率或收益承诺。
- 页面不接入银行、不代客投资、不推荐具体金融产品，也不会自动做购买/借贷/分期决策。
- “验证计划”中的项目均标注为待实测；完成西南大学本地访谈和可用性试用前，不应在报告中把它们写作已取得的结果。
- 同一输入与参数可在同一版本中重算，方便答辩时复现；请记录浏览器、输入和参数。
